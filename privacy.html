プライバシーポリシー

JARVIS は、作成者本人だけが使う個人用のアプリです。他の方のデータは扱いません。

扱うデータ

  • Google カレンダー: 予定の確認、追加、削除
  • Gmail: メールの検索と閲覧、下書きの作成、作成者が確認した下書きの送信

データの使い方

  • データは、作成者本人の依頼に答えるためだけに使います。
  • 答えを作るために、必要な内容を AI サービス (Anthropic Claude、Google Gemini) に送ります。
  • データを販売したり、広告に使ったり、第三者に共有したりしません。
  • Google へのログイン情報は、作成者本人のPCと、本人だけが接続できるサーバーに保存します。

Google API のデータについて

Google API から受け取ったデータの利用は、Limited Use の要件を含む Google API Services User Data Policy に従います。

データの削除

作成者本人が Google アカウントの設定からアクセス権を取り消すと、以後データは読み取れなくなります。
